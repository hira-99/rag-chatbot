# Framework-Free RAG & AI Agents

Build Retrieval-Augmented Generation (RAG) systems and AI agents from first principles using **Python** and direct **API/SDK calls**, without relying on orchestration frameworks.

## 🎯 Objective

This project starts with a basic chatbot and gradually evolves into a production-ready AI assistant capable of:

- 💬 Maintaining conversation history
- 📄 Answering questions from uploaded documents
- 🔍 Performing semantic and keyword search
- 🔀 Combining retrieval techniques
- 📈 Reranking search results
- 🧠 Managing short-term and long-term memory
- 🛠️ Calling external tools
- 🤖 Executing multi-step tasks
- 🔗 Connecting to MCP servers
- 👤 Requesting human approval for sensitive actions
- 📊 Tracking cost, latency, errors, and execution
- ✅ Evaluating RAG and agent performance

## 🚀 Learning Approach

The initial implementation intentionally avoids orchestration frameworks to build a strong understanding of the underlying concepts.

**Avoid initially:**
- LangChain
- LangGraph
- LlamaIndex
- CrewAI
- AutoGen
- OpenAI Agents SDK

Infrastructure libraries are still acceptable for tasks such as:

- Calling model APIs
- Generating embeddings
- Database connectivity
- File parsing
- Schema validation
- Running MCP clients and servers

## 🎓 Goal

The purpose of this roadmap is to understand how the core components of modern AI systems work and connect together before adopting higher-level frameworks.
